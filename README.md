# CreationWorks Studio LLC

Official website repository for **CreationWorks Studio LLC**.

CreationWorks is a digital studio focused on building modern, scalable and high-quality digital experiences for businesses and brands.

## Website

This repository contains the source code for the official CreationWorks Studio LLC website.

The project was built with a focus on:

- Modern user experience
- Responsive design
- Performance
- Scalability
- Clean architecture
- Visual consistency

## Development

Install dependencies:

```bash
npm install
```

Run the development environment:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

The application is optimized for modern web environments and production deployment.
